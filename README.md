# Village Trust Fund Android apps

Two Android application modules:
- VT Collector
- VT Supervisor

The first APKs are debug prototype builds, not production-ready financial software.

Original Python business-rule and signed-message prototypes are preserved at the repository root. The Android screens currently provide an initial UI shell only. Before real collection, the project still needs persistent encrypted storage, proper member management, payment allocation including the requested six-month advance rule, complete Ethiopian calendar handling, signed collector-supervisor sync, and accounting/security tests.

Advance-payment requirement: allow only complete installments, up to six future months; do not accept partial advance periods.
